# Zomorod Melal Knowledge Graph

## Goal

Connect encyclopedia topics, articles, products, services and agents into a semantic knowledge network.

## Structure

Entity
- Category
- Article
- Product
- Service
- Organization
- Location

Relations
- related_to
- belongs_to
- supports
- references

## Example

Agricultural Economics
-> Agriculture
-> Production Chains
-> Agricultural Tourism

Handmade Carpet
-> Crafts
-> Cultural Tourism

## Integration

Knowledge Graph
-> Encyclopedia Engine
-> SEO Engine
-> Master Agent
