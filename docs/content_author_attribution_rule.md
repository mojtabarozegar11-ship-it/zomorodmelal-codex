# Content Author Attribution Rule

## Purpose
All generated content across Zomorod Melal platforms must include a consistent author attribution section.

## Applies To
- Encyclopedia articles
- Newsletters
- Blog posts
- Research articles
- Educational content
- SEO content pages

## Final Attribution Format

پژوهشگر  
مدیر عامل شرکت کشت و صنعت زمرد ملل  
مجتبی روزگار

## Content Pipeline Integration

Content Agent
↓
SEO Agent
↓
Quality Review
↓
Add Attribution Block
↓
Publish

This rule is part of the content architecture and should be applied to future content templates.
