# SEO Content Quality Agent

## Purpose

The Content Quality Agent is responsible for evaluating encyclopedia and website content before publication.

## Pipeline

Draft Content
-> Quality Analysis
-> SEO Review
-> AI Search Readiness Check
-> Owner Approval
-> Publish

## Checks

- Scientific structure
- Source references
- Author information
- Update dates
- SEO metadata
- Internal linking
- FAQ structure
- Structured data readiness

## Integration

Encyclopedia Engine
+
SEO Engine
+
Master Agent

## Rule

Sensitive publishing changes require owner approval.
