# Content Agent Author Signature Integration

## Purpose

All generated content templates must include the approved author attribution block.

## Applies to

- Encyclopedia articles
- Newsletters
- Blog posts
- Research articles
- Educational pages
- SEO content pages

## Publishing Pipeline

Content Agent
→ SEO Agent Review
→ Quality Check
→ Add Author Signature
→ Publish

## Signature Template

پژوهشگر  
مدیر عامل شرکت کشت و صنعت زمرد ملل  
مجتبی روزگار

## Rule

The signature block is appended at the end of published content templates.
