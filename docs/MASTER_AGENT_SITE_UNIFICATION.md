# Master Agent ↔ Website Unification

The website is the public operational surface and the Master Agent is the operational engine.

Flow:

Website → Site-Agent Bridge → Master Agent Runtime → Policy/Approval → Execution → Verification → Audit

Required capabilities include site health, content audit, SEO audit, accessibility/performance audit, research workflows, release preparation, and business/revenue operations.

Sensitive operations require explicit approval, strong authentication where configured, and audit logging.
