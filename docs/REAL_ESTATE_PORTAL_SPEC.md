## نکته یکپارچه‌سازی
شاخه main فعلی کد اجرایی کامل Django را در اختیار ندارد؛ این بسته عمداً self-contained ساخته شده است تا به محض بازگشت canonical Django tree، بدون بازطراحی محتوا و UI در پروژه اصلی ادغام شود.
