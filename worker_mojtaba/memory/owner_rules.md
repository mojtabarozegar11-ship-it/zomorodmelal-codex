# حافظه بلندمدت — قوانین مالک

## قانون دائمی
- پروژه «کارگر مجتبی» باید به‌صورت ۲۴/۷ برای پیگیری، نگهداری، توسعه و اجرای برنامه‌های مجاز آماده باشد.
- مالک پروژه مجوز گسترده برای اتصال سرویس‌ها و ابزارهای موردنیاز را اعلام کرده است.
- دسترسی واقعی همیشه باید از طریق احراز هویت، API، مجوز سیستم‌عامل یا اتصال معتبر همان سرویس فراهم شود.
- این سند فقط تنظیمات و ترجیحات پروژه را ثبت می‌کند و شامل رمز عبور، کلید خصوصی یا Secret نیست.

## سیاست دسترسی
- دسترسی‌ها باید قابل ممیزی، قابل لغو و قابل پیکربندی باشند.
- عملیات حساس باید مطابق مجوزهای واقعی سرویس و سیستم‌عامل اجرا شوند.
