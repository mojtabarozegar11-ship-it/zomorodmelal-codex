# کارگر مجتبی

پروژه مستقل دستیار شخصی هوشمند اندروید.

## هدف
ساخت یک Agent عملیاتی که از طریق چت و صدا درخواست را دریافت کند، برنامه‌ریزی کند، ابزارهای مجاز را انتخاب کند و نتیجه را به کاربر تحویل دهد.

## اجزای اصلی
- Core Brain
- Memory
- Planner
- Model Router
- Tool Engine
- Agent Factory
- Evolution Engine
- Scientist Engine
- Security Engine
- Android Device Engine
- Media Engine
- Digital Asset Engine
- Personal Automation
- Dashboard
- Backup & Recovery

نسخه 0.1 — اسکلت اولیه پروژه.
